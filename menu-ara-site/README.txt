منو آرا - وب‌سایت استاتیک HTML و CSS

1) فایل‌های index.html و style.css را در یک پوشه نگه دارید.
2) برای مشاهده محلی، روی index.html دوبار کلیک کنید.
3) برای انتشار در GitHub:
   - یک repository جدید بسازید.
   - فایل‌های index.html و style.css را در ریشه repository آپلود کنید.
   - از Settings > Pages، گزینه Deploy from a branch را انتخاب کنید.
   - Branch را روی main و پوشه را روی /(root) قرار دهید و Save بزنید.
   - پس از چند دقیقه، آدرس سایت در همان صفحه نمایش داده می‌شود.

قبل از انتشار:
- ایمیل hello@menuara.example را در index.html با ایمیل واقعی جایگزین کنید.
- تعرفه‌ها، زمان تحویل و متن نمونه‌کارها را بررسی و واقعی‌سازی کنید.
- فرم سفارش فعلاً وجود ندارد؛ لینک ایمیل فقط برنامه ایمیل مخاطب را باز می‌کند.
- فونت Vazirmatn از Google Fonts بارگذاری می‌شود و برای نمایش آن اینترنت لازم است.
